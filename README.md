# StudyPlus — UX/UI Prototype

StudyPlus is a high-fidelity mobile application prototype designed to help students manage 
study sessions, track academic progress, and set study goals.

## Overview

This project focused entirely on user experience design and interface prototyping rather 
than development. The goal was to produce a prototype that felt like a real, shippable 
product — not a wireframe. Every screen and interaction was designed with specific UX 
principles in mind, and design decisions were documented and justified against established 
frameworks rather than made arbitrarily. The result is a fully navigable Figma prototype 
covering the application's core user journeys end to end.

## My Role

Sole UX/UI designer — responsible for all screen designs, user flows, interaction design, 
principle application, and written design justification.

## Design Approach

**Don Norman's Design Principles**
Visibility, feedback, affordances, mappings, constraints, and consistency were applied 
across every screen. The aim was an interface where the right action is always obvious 
and errors are difficult to make.

**Shneiderman's Eight Golden Rules**
Consistency, shortcuts, informative feedback, closure, error prevention, reversal, user 
control, and reduced memory load shaped layout and interaction decisions throughout — 
particularly around navigation, form design, and progress feedback.

## User Flows Covered

- User authentication (register and login)
- Study session creation and management
- Active study session tracking
- Academic progress monitoring and history
- Study goal setting and adjustment
